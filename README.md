# privacidad / me

Hub central del ecosistema de privacidad de Stark Privacy.

Enlaza:
- **privtr.ee** — identidad digital y enlaces sin rastreo
- **privacidad/tools** — herramientas locales en el navegador
- **privacidad/news** — noticias de privacidad
- **boringprivacy.io** — Academia

Estilo: DedSec (Watch Dogs) adaptado a la paleta azul-neón del resto de proyectos.
